# 🏹 Archer Battle 2D

2D lokostrelska igra **igralec proti AI**, narejena v Unity 6 (6000.6) z Universal Render Pipeline.

## Zagon
1. V Unity Hub izberi **Add → Add project from disk** in izberi to mapo (`Lokostrelstvo`).
2. Odpri projekt z Unity **6000.6.7f1** (ali novejšo 6000.6.x).
3. Odpri `Assets/Scenes/SampleScene` in pritisni **Play**.

Vsa grafika, zvoki in meniji se ustvarijo s kodo ob zagonu, zato ni treba uvažati nobenih datotek.

## Kontrole
| Tipka | Akcija |
|---|---|
| A / D | premikanje levo / desno |
| SPACE / W | skok |
| Miška | merjenje |
| Drži levi klik | napenjanje loka |
| Spusti levi klik | strel |
| ESC | pavza |

Več podrobnosti: [`Assets/ArcherBattle/NAVODILA.md`](Assets/ArcherBattle/NAVODILA.md).
